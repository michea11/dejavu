# déjà vu

> 同じバグを何度もデバッグする必要はない。
> 一つの視点だけで判断を下すべきではない。

**déjà vu** は、AI コーディングにおける無駄な「再思考」を排除するために作られた、依存ゼロの 2 つのスキルを含む Claude Code プラグインです。

---

## インストール

```bash
# セルフホストマーケットプレイスを追加（初回のみ）
/plugin marketplace add michea11/dejavu

# プラグインをインストール
/plugin install dejavu@michea11-dejavu
```

---

## 使い方

```bash
# gotcha — トラブルシューティングメモリ、grep + ファイルシステム、依存ゼロ

/gotcha save              # 直近のデバッグセッションを gotcha として保存
/gotcha <キーワード>       # マッチする gotcha を検索、ヒット時に内容を注入
/gotcha                    # 全 gotcha を新しい順に一覧表示
/gotcha fix <slug>         # 修正済みとしてマーク（記録は残し、次回マッチ時に注釈）
/gotcha delete <slug>      # gotcha を削除（確認あり）

# flip — 視点転換、純粋なプロセススキル、ファイル I/O なし

/flip                      # 最新の結論を、見落としている視点から検証
/flip "use redis for caching"  # 特定の結論を検証
```

---

## なぜ使うべきか

AI コーディング最大の隠れたコストは GPU ではなく、**すでに解決した問題を再考すること**です。

| シナリオ | 従来 | déjà vu 導入後 |
|---|---|---|
| 先週と同じエラーで CI が失敗 | 10 ラウンドのデバッグを最初から | `/gotcha CI killed` → 即解決 |
| 誰も反対しないからプラン A を採用 | 本番環境で盲点が見つかる | `/flip` → リリース前に発見 |
| 同じ落とし穴に 3 回目 | 毎回ゼロからやり直し | gotcha 検索 → 3 秒で確認 |
| この判断、何か引っかかる | 迷ったまま進める | `/flip` → 体系的なレビュー |

**毎回のヒットで節約されるのはトークンだけでなく、集中力と何時間もの会話です。**

## 2 つのスキル

### gotcha — トラブルシューティングメモリ

```
バグに遭遇 → /gotcha save → 修正を保存 → /gotcha <キーワード> → 即座に思い出す
```

- grep ベースの検索、依存ゼロ、ミリ秒の応答
- インデックス事前注入なし — ミス時もトークン消費ゼロ
- セッション終了時の優しいリマインダー、邪魔にならない

### flip — 視点転換

```
決定を下そうとしている → /flip → 見落としている視点を発見 → 盲点を早期に捕捉
```

- 単なる「反対意見」に留まらず、欠けている視点を見つける
- コスト、時間、新人、極端なケース、スケール — 欠けている視点なら何でも
- 重要な判断ポイントで積極的にヒント、それ以外は静か

## クロスプラットフォーム

同じ `SKILL.md` がすべての主要 AI コーディングツールで動作：

| ツール | スキルディレクトリ |
|---|---|
| Claude Code | `.claude/skills/` |
| OpenAI Codex CLI | `.agents/skills/` |
| Cursor | `.cursor/skills/` |
| GitHub Copilot | `.github/skills/` |
| Windsurf | `.windsurf/skills/` |
| Gemini CLI | `.gemini/skills/` |

一度のクローンで、各ツールが適切なディレクトリを自動的に読み込みます。Claude Code はフル機能版、他のプラットフォームは共通サブセット版を使用。

## 設計理念

- **トークンを無駄にしない** — インデックス事前注入なし、サイレントバックグラウンドマッチなし、オンデマンド検索のみ
- **外部依存ゼロ** — grep + ファイルシステム、埋め込み API なし、ベクトルデータベースなし
- **集中力を妨げない** — 保存するかどうかはあなた次第、セッション終了時に一度だけ優しくリマインド
- **決めるのはあなた** — 経験と視点を提供するだけで、結論は常にあなたのもの
